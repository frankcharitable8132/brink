
### Added
- **Brink for Windows** — native C# / WPF port in `windows/`, with the same rings, detail card, notifications, 10 languages, launch at login and provider handling. Ships as a single self-contained `Brink.exe` (`Brink-Windows-x64.zip`) built by GitHub Actions on every release.


**Downloads:** `Brink.dmg` (macOS 13+, universal) · `Brink-Windows-x64.zip` (Windows 10/11). Checksums in `SHA256SUMS-*.txt`; verify provenance with `gh attestation verify <file> -R semihtalii/brink`.

Not notarized yet — see [Install](https://github.com/semihtalii/brink#install) for the one-time Gatekeeper / SmartScreen step.
